Lottie Animaties

Een praktische demo van alle manieren om Lottie JSON-animaties te integreren: inline afspelen, scroll-triggers, hover-interactie, snelheidscontrole en combinatie met GSAP.

Introductie

Wat Is Lottie?

Lottie is een open-source bibliotheek die After Effects animaties (geëxporteerd als JSON via het Bodymovin-plugin) afspeelt in de browser. Lichtgewicht, schaalbaar als SVG, en volledig programmeerbaar via JavaScript.

Minimale Setup
Laad Lottie via CDN, voeg een container toe en roep loadAnimation aan. 
<!-- 1. CDN in <body> -->
<script src="https://cdn.jsdelivr.net/npm/lottie-web@5.12.2/build/player/lottie.min.js"></script>

<!-- 2. Container in HTML -->
<div id="mijn-animatie"></div>

<!-- 3. JavaScript -->
const anim = lottie.loadAnimation({
  container: document.getElementById('mijn-animatie'),
  renderer:  'svg',      // 'svg' | 'canvas' | 'html'
  loop:      true,
  autoplay:  true,
  path:      'animatie.json',
});

Inline Afspelen

Lottie geladen met een publieke JSON-URL. De knoppen laten de volledige programmatische API zien die je altijd beschikbaar hebt.

Live Player
// loadAnimation configuratie
const mainAnim = lottie.loadAnimation({
  container: document.querySelector('#lottie-main'),
  renderer:  'svg',
  loop:      true,
  autoplay:  true,
  path:      'animatie.json',

  // Of gebruik animationData voor inline JSON:
  // animationData: import('./animatie.json'),
});

// Afspelen
mainAnim.play();
mainAnim.pause();
mainAnim.stop();

// Richting: 1 = vooruit, -1 = achteruit
mainAnim.setDirection(-1);

// Spring naar frame 30 en stop
mainAnim.goToAndStop(30, true);

// Spring naar frame 30 en speel door
mainAnim.goToAndPlay(30, true);

// Luister naar events
mainAnim.addEventListener('complete', () => {
  console.log('Animatie klaar!');
});
Referentie

Alle Methoden

Elk loadAnimation object geeft je volledige controle via onderstaande methoden.

.play()
Start of hervat de animatie vanaf het huidige frame.
.pause()
Pauzeert op het huidige frame. Hervat met play().
.stop()
Stopt en keert terug naar frame 0.
.setSpeed(n)
1 = normaal, 2 = dubbel, 0.5 = half.
.setDirection(n)
1 = vooruit, -1 = achteruit.
.goToAndStop(f, true)
Spring naar frame f en stop daar.
.goToAndPlay(f, true)
Spring naar frame f en speel door.
.playSegments([a,b], true)
Speel alleen frames a t/m b af.
.destroy()
Verwijder de animatie en ruim geheugen op.
.totalFrames
Eigenschap: totaal aantal frames in de animatie.
.currentFrame
Eigenschap: huidig frame (alleen-lezen).
.addEventListener
Events: complete, loopComplete, enterFrame, segmentStart.

Scroll-Triggered Animaties

Lottie gesynchroniseerd met scroll via IntersectionObserver. De animatie start pas als het element zichtbaar is — ideaal voor secties.

Play On Enter
Start eenmalig als het element in beeld scrollt.
Loop On Enter
Loopt door zolang het element zichtbaar is, pauzeert als het wegscrollt.
Delay On Enter
Wacht 600 ms na het in beeld komen voor een subtiel effect.
Scroll Trigger Code
// Patroon: start animatie als element zichtbaar wordt
function lottieOnScroll(containerSelector, path, options = {}) {
  const el = document.querySelector(containerSelector);

  const anim = lottie.loadAnimation({
    container: el,
    renderer:  'svg',
    loop:      options.loop ?? false,
    autoplay:  false,       // ← altijd false, wij triggeren zelf
    path,
  });

  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        setTimeout(() => anim.play(), options.delay ?? 0);
        if (!options.loop) observer.unobserve(el); // eenmalig
      } else if (options.loop) {
        anim.pause(); // pauze als uit beeld
      }
    });
  }, { threshold: 0.3 });

  observer.observe(el);
  return anim;
}

// Gebruik
lottieOnScroll('#mijn-animatie', 'animatie.json');
lottieOnScroll('#loop-animatie',  'animatie.json', { loop: true });
lottieOnScroll('#delay-animatie', 'animatie.json', { delay: 600 });

Hover Code
// Patroon: animeer vooruit op hover, achteruit bij mouseleave
function lottieHover(cardSelector, animContainerSelector, path) {
  const card = document.querySelector(cardSelector);
  const anim = lottie.loadAnimation({
    container: document.querySelector(animContainerSelector),
    renderer:  'svg',
    loop:      false,
    autoplay:  false,
    path,
  });

  card.addEventListener('mouseenter', () => {
    anim.setDirection(1);
    anim.play();
  });
  card.addEventListener('mouseleave', () => {
    anim.setDirection(-1);
    anim.play();
  });
  return anim;
}

// Klik-variant: speel segment A→B op klik, B→eind op tweede klik
function lottieToggle(cardSelector, animContainerSelector, path) {
  let toggled = false;
  const card  = document.querySelector(cardSelector);
  const anim  = lottie.loadAnimation({
    container: document.querySelector(animContainerSelector),
    renderer: 'svg', loop: false, autoplay: false, path,
  });
  card.addEventListener('click', () => {
    toggled = !toggled;
    anim.setDirection(toggled ? 1 : -1);
    anim.play();
  });
  return anim;
}

GSAP + Lottie Combinatie

Gebruik GSAP om de Lottie frame-positie te sturen vanuit scroll, zodat de animatie exact gesynchroniseerd is met jouw ScrollTrigger.

Scroll op de pagina — de animatie hieronder wordt aangestuurd via goToAndStop(frame, true) vanuit een GSAP ScrollTrigger proxy. Zo loop je frame-voor-frame door de animatie terwijl de gebruiker scrollt.

GSAP ScrollTrigger → Lottie Frame
// GSAP + Lottie scroll-scrub patroon
const anim = lottie.loadAnimation({
  container: document.querySelector('#scroll-lottie'),
  renderer:  'svg',
  loop:      false,
  autoplay:  false,   // ← GSAP neemt het over
  path:      'animatie.json',
});

// Wacht tot Lottie geladen is
anim.addEventListener('DOMLoaded', () => {
  // Proxy-object dat GSAP kan tweenen
  const proxy = { frame: 0 };

  gsap.to(proxy, {
    frame: anim.totalFrames - 1,
    ease:  'none',
    scrollTrigger: {
      trigger: '#scroll-lottie',
      start:   'top center',
      end:     'bottom top',
      scrub:   0.5,             // smooth scrub
    },
    onUpdate: () =>
      anim.goToAndStop(proxy.frame, true),
  });
});
